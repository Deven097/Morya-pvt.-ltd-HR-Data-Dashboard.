# 📊 HR Analytics Dashboard – Microsoft Excel

## 📌 Project Overview

The **HR Analytics Dashboard** is a Microsoft Excel project developed to analyze employee data and present important HR metrics through interactive visualizations and reports. The project focuses on transforming raw employee information into meaningful insights that can help understand workforce distribution, payroll, attendance, and employee performance.

The dashboard provides a clear overview of key HR indicators, allowing users to explore employee-related data and identify useful patterns across departments, offices, designations, and employment categories.

## 🎯 Project Objectives

- Analyze employee data to understand workforce distribution.
- Monitor payroll and average salary across departments.
- Evaluate employee attendance and ratings.
- Explore employee distribution by age group and designation.
- Present important HR metrics in an interactive dashboard.
- Summarize findings to support data-driven decision-making.

## 🛠️ Tools and Techniques Used

- **Microsoft Excel**
- Excel formulas and functions
- Pivot Tables
- Interactive dashboard design
- Charts and data visualization
- Slicers and interactive filtering
- Data summarization and reporting

## 📂 Workbook Structure

The workbook contains the following sheets:

- **HOME:** Main landing page for the project.
- **DASHBOARD:** Interactive HR dashboard displaying key metrics and visualizations.
- **KEY INSIGHTS:** Dedicated sheet for presenting important findings.
- **PIVOT TABLE:** Summarized data used to support dashboard analysis.
- **MAIN DATA:** Employee dataset containing details such as employee ID, age, department, office location, designation, manager, employment type, salary, attendance, rating, and years of experience.

## 📈 Key Metrics and Analysis

The dashboard includes metrics and analysis related to:

- Number of departments
- Average employee attendance
- Total payroll
- Number of office locations
- Average employee salary
- Salary distribution by department
- Average attendance by designation
- Employee distribution by age group and designation
- Employee information such as employment type, rating, shift, and status

## 💡 Project Benefits

This project demonstrates how Microsoft Excel can be used to organize employee data, summarize large datasets, create interactive dashboards, and communicate business insights effectively. It also highlights the value of data visualization in making HR information easier to understand.
