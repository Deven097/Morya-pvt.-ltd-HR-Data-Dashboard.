My Excel HR Analytics project focuses on analyzing employee data to understand salary distribution, attendance, employee ratings, and department-wise performance. Using Excel formulas, Pivot Tables, and charts such as bar charts, column charts, and pie charts, I created an interactive HR dashboard featuring KPI cards, slicers, and drop-down filters to make data exploration easier. The dashboard helps present workforce trends and key insights clearly, supporting better data-driven decision-making.

Tool Used: Microsoft Excel
